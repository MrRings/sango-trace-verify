sango trace

Wild-harvest traceability, starting with baobab in Gwanda, Zimbabwe.

Scanned a QR code on a batch?

Scan it again with your phone camera. It opens the certificate for that batch: where it was harvested, when, the quality grade, and the hand-offs since. If you got here by typing the address, the certificate page needs the code from the QR.

What a certificate shows

Weight and grade of every lot, a GPS point and date for each harvest, the part of the plant collected, and a seal that changes if any record is altered afterwards. Harvesters appear by ID code only.

About

Sango Trace is built by Inala Africa Trust, Harare. The certificate is evidence of origin and handling. It is not a FairWild or organic certification.
